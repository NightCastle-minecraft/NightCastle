# SiteGate

**Вход на Minecraft-сервер через свой сайт.** Игрок заходит в игру, решает капчу, нажимает кнопку «Нажмите, чтобы авторизоваться». Открывается ваш сайт: там он регистрируется или вводит пароль и подтверждает вход. Пароль в игре не вводится никогда. Лицензия Minecraft у игроков не нужна, ник защищён паролем на сайте.

В комплекте целая система: два плагина, сайт, Docker-стек для VPS и панель управления.

```
игрок ──► example.com:25565 ──► Velocity + SiteGateAuth ──► SMP (Paper/Leaf 26.3 + SiteGateShop)
                                     │ HTTPS API                    │ HTTPS API
                                     ▼                              ▼
                           сайт: Caddy (HTTPS) → PHP 8.3 → 3 базы MySQL/MariaDB
                           почта: Postfix + DKIM → письма игрокам
                           панель: статус, консоль, игроки, бэкапы (через SSH-туннель)
```

## Что умеет
- **SiteGateAuth** (плагин Velocity 4.3.1):
  - капча и окно с кнопкой входа прямо в игре, ещё до подключения к серверу (окна-диалоги Minecraft 26.3 в фазе конфигурации);
  - вход подтверждается на сайте, после этого 7 дней игра пускает с того же IP без сайта;
  - лимиты входов, бан IP за проваленную капчу;
  - учёт наигранного времени.
- **SiteGateShop** (плагин Paper/Leaf 26.3):
  - выдаёт покупки из магазина на сайте командами из `products/<код>.yml`, в том числе пока игрок не в игре;
  - защищён от повторной выдачи;
  - команда `/shop` показывает баланс и ссылку на магазин.
- **Сайт** (PHP 8.3 без фреймворка):
  - для игроков: новости, правила, регистрация на сайте или из игры, личный кабинет с наигранным временем, балансом и покупками;
  - почта: подтверждение адреса, сброс пароля по ссылке;
  - магазин на внутренних монетах;
  - админка: новости, правила, страницы, игроки, товары, заказы, кошельки, размеры баз.
- **Стек** (Docker Compose):
  - Caddy с автоматическим HTTPS, сайт, Postfix только на отправку, Velocity, SMP;
  - SMP и почта наружу не открыты.
- **Панель** (один файл на Python, только stdlib):
  - запуск, остановка и консоль серверов;
  - игроки: кик, бан, op, вайтлист, а также аккаунт на сайте и баланс;
  - бэкапы мира по расписанию, редактор конфигов, плагины.

| Папка | Что это |
|---|---|
| [`plugins/`](plugins/) | Плагины на Java 25 (Gradle): `auth` → SiteGateAuth, `shop` → SiteGateShop, `tools` → моки сайта и мини-клиент для проверок |
| [`site/`](site/) | Сайт: `src` (PHP), `templates`, `public`, `migrations`, `bin` (миграции, админ, аккаунты), `tests` (PHPUnit) |
| [`infra/`](infra/) | Docker Compose, конфиг Caddy, шаблоны конфигов Velocity и плагинов, панель `infra/panel` |

## Требования
- VPS с Linux, Docker и Docker Compose v2. Памяти от 4 ГБ, лучше 8: на 20 игроков SMP нужно 3–5 ГБ.
- Домен и доступ к его DNS.
- Сервер Paper или Leaf под Minecraft 26.3. Клиенты должны быть 26.3: окна-диалоги работают с 1.21.6.
- Базы MySQL 8 или MariaDB 10.4+: от одной до трёх.
- Для сборки плагинов: JDK 25.
